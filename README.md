# ThreatVault

ThreatVault is a cybersecurity threat intelligence database management system built with Python and SQLite. (This project was created for Database Management Systems)

## Features
- Relational database design
- SQL JOIN/GROUP BY/HAVING queries
- Incident tracking
- Threat intelligence management
- Python command-line interface
- Error handling

## Technologies Used
- Python
- SQLite
- SQL
- VS Code
- GitHub

## Database Concepts Demonstrated
- Primary Keys
- Foreign Keys
- One-to-Many Relationships
- Many-to-Many Relationships
- JOIN Queries
- GROUP BY Queries
- HAVING Clauses
